# TaskPulse OS — Developer Task Engine

A modern engineering task manager and productivity dashboard built with pure HTML5, CSS3, and modern Vanilla JavaScript (ES6+).

## Live Demo
- **Live Site:** `https://deeppurohit7.github.io/todo-list-app/`
- **Source Code:** `https://github.com/deeppurohit7/todo-list-app`

## Key Features
- **Live Velocity Telemetry:** Real-time completion percentage calculations and dynamic progress bar.
- **Priority & Categorization:** Assign High, Medium, or Low priority badges and categorize tasks (Dev, Roadmap, Career).
- **Persistent State:** Saves automatically to `window.localStorage` across sessions.
- **Event Delegation Architecture:** Scalable DOM interaction handling with XSS sanitization.
- **JSON Backup:** One-click task state backup export.
